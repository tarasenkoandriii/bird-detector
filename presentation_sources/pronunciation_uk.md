# Нотатки з вимови для українського озвучення

Голос: Soniox Daniel. Мова: українська. Темп: 1,15×. Це підказки для слухової перевірки; латинські скорочення на слайдах лишаються без змін.

## Узгоджені форми

- `YOLO26n` у тексті для диктора: **Йоло двадцять шість ен**.
- `CUB` у тексті для диктора: **Сі-Ю-Бі**.
- `mAP50–95` у тексті для диктора: **ем-ей-пі від п’ятдесяти до дев’яноста п’яти**.
- `mAP` у тексті для диктора: **ем-ей-пі**.
- `AdamW` у тексті для диктора: **Адам Дабл-Ю**.
- `CPU` у тексті для диктора: **сі-пі-ю**.
- `MPS` у тексті для диктора: **ем-пі-ес**.
- `FPS` у тексті для диктора: **кадрів за секунду**.
- `seed` у тексті для диктора: **сід**.
- `head-only` у тексті для диктора: **лише голова**.
- `head3` у тексті для диктора: **голова три**.
- `head5` у тексті для диктора: **голова п’ять**.
- `neck` у тексті для диктора: **нек**.
- `GT` у тексті для диктора: **еталонна розмітка**.
- `AP` у тексті для диктора: **ей-пі**.

## Числа й степені

- `3e−6` читати словами: **три на десять у мінус шостому степені**. Не читати літеру e окремо й не пропускати від’ємний знак.
- Десяткові значення читати з українською комою; у плавному викладі допустиме читання цифр після коми окремо.
- Відсоткові пункти вимовляти повністю як **відсоткового пункту / відсоткові пункти**, не як «відсотка» там, де порівнюється абсолютна різниця.
- Мінуси в змінах перед числом обов’язково озвучувати: **мінус…** або **зменшення на…**.
- Перед прийманням окремо звірити у фінальному аудіо степеневий запис, `CUB`, `YOLO26n`, малі дельти та десяткові дроби.
