# Джерела презентації Bird Detector

Поточна редакція містить 60 слайдів. Джерельний коміт моделі й звітів: `f64dd6601c1f5ab6cf87e1444672711a95a0d2e6`.

- `storyboard.md` — план слайдів, візуалізації та джерела чисел.
- `narration_uk.md` — текст диктора.
- `pronunciation_uk.md` — вимова скорочень, десяткових значень і степенів.
- `reuse_map.md` — відповідність старих слайдів новим та статус медіа.
- `metrics_manifest.json` — перелік джерел вимірів.
- `media_manifest.json` — SHA256 файлів рендера й прикладу.
- `soniox_settings.json` — цільові налаштування синтезу; це не підтверджує створення аудіо.
- `qa_report.md` — перевірене та невиконане.

Окремі кліпи, зведене аудіо, SRT/VTT і фінальний MP4 ще не згенеровані. Комплект не вважати повністю озвученим або готовим до публікації.
