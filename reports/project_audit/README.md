## Що змінилося в запуску

`evaluate.py` типово створює новий звіт у `runs/evaluate/`; історичні `reports/*.json` не замінюються. Явний наявний `--report` потребує `--overwrite`. Нові оцінки зберігають хеші фактичних зображень/GT, YAML, ваг і evaluator; дані й ваги перевіряються до/після.

`compare_profiles.py` перевіряє split, розмір, batch, пристрій, версії, дані й evaluator. Погіршений D більше не оголошується основним. Ваги скрипт не змінює. Нові звіти порівняння записуються окремо в `runs/`.

Старі JSON не містять хешів GT/evaluator. Для них потрібен явний `--allow-legacy`; результат має позначку непідтвердженої provenance. Відсутні хеші не дописано заднім числом. Історичний D проходить числове правило, його поточний статус не змінився.

VFR перетворюється на постійний середній FPS — індивідуальні часові мітки не зберігаються. Це тепер явно описано. Швидкість циклу включає перший forward; вона не називається прогрітим benchmark. Для непарних розмірів H.264/yuv444p має обмежену браузерну сумісність.
