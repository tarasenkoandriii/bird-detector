# Bird video detection v2

102 train / 32 development-validation. Розмітка асистента за оригінальними кадрами, без передбачень моделей; це не незалежний людський аудит.

Рамка охоплює всі видимі частини кожного птаха: дзьоб, голову, тулуб, крила, хвіст, видимі ноги/стопи. Не домислювати прихованих частин. Усі видимі справжні птахи; не логотипи, не малюнки, не риба/здобич. Незмінний legacy; v2 development validation, не незалежний test. Віддзеркалення у воді не вважати окремим птахом; об’єкти здобичі не входять до bird bbox.

Legacy збережена. 8 негативних validation-вирізок і всі зображення скопійовані байт-в-байт. Ця версія GT несумісна зі старими значеннями mAP; моделі потрібно оцінити заново. Validation містить дві відомі послідовності, це не новий незалежний test.

Походження, старі/нові bbox, хеші та обмеження — у manifest.json.
