# Експерименти з роздільністю та постобробкою

Класифікаційні ваги до bbox-етапів; validation — 200 зображень, CPU. Це історичні результати, не оцінка поточного релізу.

| Розмір | mAP50 | mAP50–95 |
|---|---:|---:|
| 320 | 97,04% | 77,58% |
| 448 | 97,43% | 78,96% |
| 512 | 97,71% | 80,49% |
| 576 | 97,87% | 80,27% |
| 640 | 97,91% | 79,46% |
| 768 | 97,93% | 76,16% |
| 960 | 93,79% | 63,60% |
| 1280 | 70,48% | 29,22% |

512 дав найкращу локалізацію на validation, але на тих самих 100 test-зображеннях програв 640: **78,34% проти 79,48% mAP50–95**. Типовий режим залишився 640.

При 640 додатковий NMS дав 78,48%, об’єднання звичайного й дзеркального прогнозів — 79,86% проти 79,46% одного проходу. Малий виграш рамок не виправдав додаткового проходу; mAP50 зменшився. Режим не включено до відеопайплайна.

Джерела: [роздільності 448–768](resolution_refinement.json), [960–1280](resolution_sweep.json), [постобробка](quality_sweep.json), [test при 512](test_512.json), [test при 640](head_stage_test_640.json). Додатковий NMS при 512: [79,67% mAP50–95](nms_512_validation.json).

Повторення експериментів потребує відповідних класифікаційних ваг. Запуск на поточному best.pt буде новим експериментом. Підсумок етапів — [improvement.md](improvement.md).
